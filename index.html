1. What is a Computer?

Definition: A computer is an electronic device that performs processes, calculations and operations based on instructions provided by a software or hardware program. It has the ability to accept data (input), process it, and then produce outputs.

Simplest Workflow: Input → Process → Output

Computer input is called data and the output obtained after processing it (based on user’s instructions) is called information.

2. Data vs Information

Data

  • Raw facts and figures
  • Unorganized
  • Without context
  • Can be quantitative (numerical) or qualitative (descriptive)
  • Examples: number of website visitors, individual customer survey responses, product price

Information

  • The result of analyzing and interpreting data
  • Organized
  • Has context
  • Can be used to help make decisions
  • Examples: website traffic changes, customer sentiment based on survey results, product price comparison

Processes applied to data

  • Arithmetic operations – addition, subtraction, differentials, square root, etc.
  • Logical operations – greater than, less than, equal to, opposite, etc.

3. Basic Parts of a Computer

  • Input Unit – Devices like keyboard and mouse that input data and instructions.
  • Output Unit – Devices like printer and visual display unit that provide information in desired format.
  • Control Unit (CU) – Controls all functions of the computer. All devices interact through it.
  • Arithmetic Logic Unit (ALU) – The “brain” where all arithmetic and logical operations take place.
  • Memory – Stores input data, instructions and intermediate data. Two types: Primary (inside CPU) and Secondary (external).
CPU = Control Unit + Arithmetic Logic Unit + Memory
Hardware = physical parts we can see and touch.
Software = set of instructions/programs that make hardware work (we cannot touch it).

4. Characteristics of Computer

  • Speed – Can carry out 3–4 million instructions per second (typically).
  • Accuracy – Very high degree of accuracy. Errors are usually due to human mistakes (wrong data, wrong instructions, chip bugs).
  • Reliability – Can do the same work repeatedly without tiredness or boredom.
  • Versatility – Wide range of work: data entry, ticket booking, complex calculations, astronomical observations.
  • Storage Capacity – Stores huge amount of data at low cost; safe from normal wear & tear of paper.

5. Advantages & Disadvantages

Advantages

  • Same task repeatedly with same accuracy
  • Do not get tired or bored
  • Take up routine tasks → free humans for intelligent work

Disadvantages

  • No intelligence – follow instructions blindly
  • Need regular electric supply (problem in developing nations)

6. Booting

Starting a computer or computer-embedded device is called booting.

Steps:

  1. Switching on power supply
  2. Loading operating system into computer’s main memory
  3. Keeping all applications in a state of readiness

The first program that runs is BIOS (Basic Input Output System) – a firmware permanently programmed into the hardware.

Two types of Booting

Cold BootingWarm Booting
System started by switching on the power supply. BIOS is loaded. System is already running and needs restart/reboot. Faster because BIOS is not reloaded.

Rebooting may be required after software/hardware installation or when system is unusually slow.

7. Hardware & Software

Hardware

“Any physical parts or components that contribute to a computer system.” Tangible components that can be seen and touched.

  • Input devices – keyboard, mouse
  • Output devices – printer, monitor
  • Secondary storage – Hard disk, CD, DVD
  • Internal components – CPU, motherboard, RAM

Software

Software is a set of programs designed to perform a well-defined function. A program is a sequence of instructions written to solve a particular problem.

Two main categories: System Software and Application Software.

8. System Software vs Application Software

System Software

Collection of programs designed to operate, control and extend the processing capabilities of the computer itself. Prepared by computer manufacturers. Written in low-level languages. Acts as interface between hardware and end users.

Examples: Operating System, Compilers, Interpreters, Assemblers, Device Drivers, Language Processors.

  • Closer to the computer system
  • Written in low-level language
  • Difficult to design and understand
  • Fast in speed
  • Less interactive for users

Key System Software

  • Operating System – First software that loads; manages all resources (memory, CPU, printer, disk…); provides user interface.
  • Language Processor – Converts high-level source code (Java, C, Python…) into machine/object code.
  • Device Driver – Controls a device (printer, mouse, modem…) so OS knows how to manage it.

Application Software

Designed to satisfy a particular need of a particular environment. May be a single program (Notepad) or a package (MS Office).

  • Performs specialized tasks (word processing, spreadsheets, email…)
  • Usually larger → needs more storage
  • More interactive, easy to use and design
  • Written in high-level language

Types of Application Software

  • General Purpose – MS-Word, Excel, PowerPoint
  • Customized – Railway reservation, airline reservation, invoice system
  • Utility – Antivirus, disk cleaner, disk defragmenter, registry cleaner

9. Interface

An interface is a shared boundary across which two or more separate components of a computer system exchange information.

Hardware Interface

Described by mechanical, electrical and logical signals + protocol. Can be parallel (several connections at once) or serial (one bit at a time). Example: SCSI.

Software Interface

Can exist at many levels (OS ↔ hardware, application ↔ OS, objects ↔ methods). Provides controlled access to resources (memory, CPU, storage). Direct access without proper interfaces can be disastrous for stability.

10. Operating System (OS)

An OS is a resource manager that manages all hardware resources (CPU, RAM, Disk, Network, I/O devices). It also controls application software & device drivers, manages system security and handles multi-user access. It is the most important system software.

Examples: Windows, Linux, Android, macOS, Unix, MS-DOS.

Primary Objectives

  1. Provide services for building and running application programs (load program into memory, allocate CPU, decide execution order).
  2. Provide a user interface so the user can interact with the computer.

11. Functions of Operating System

(A) Process Management

A task in execution is a process. OS manages multiple processes, allocates CPU (most important resource), and handles information exchange between processes. Goal: complete multiple tasks in minimum time.

(B) Memory Management

Primary memory is limited. OS dynamically allocates and frees memory to running processes without affecting others. Keeps track of every free/occupied location so maximum memory is utilized.

(C) File Management

Data & programs stored as files in secondary storage. Involves creation, update, deletion and protection of files. Prevents unauthorized access by other users.

(D) Device Management

Manages heterogeneous interdependent I/O devices via device drivers. Provides configuration options and restricts access to authorized users/software/hardware only.

13. Processor / CPU

Processor (CPU) is logic circuitry that responds to and processes the basic instructions that drive a computer. It receives program instructions and executes calculations.

Capability measured by: max bits/instructions, relative clock speed, ability to process instructions at a given time.

Instruction Cycle (3 main steps)

  1. Fetch – retrieves instruction (usually from RAM)
  2. Decode – decoder converts instruction into signals for other components
  3. Execute – decoded instructions sent to components to perform the operation

(Sometimes a 4th step: Store results back to memory)

Components of a Processor

  • Control Unit (CU) – directs operations; coordinates data flow; understands commands; regulates flow; turns external instructions into control signals; manages ALUs, buffers, registers.
  • ALU (Arithmetic Logic Unit) – performs arithmetic & logic operations; also called Integer Unit (IU).
  • Registers – high-speed memory that accept, transfer and store data & instructions currently being used; instruct ALU and store results.
  • Cache – smaller, faster memory close to the core. Stores copies of frequently used data.
    • L1 – primary, embedded on chip (smallest, fastest)
    • L2 – secondary, on-chip or separate high-speed bus
    • L3 – specialized backup for L1 & L2 (boosts performance)

Types of Processors (by cores)

  • Single-core – one core; one fetch-decode-execute per clock cycle; slower, less demand now.
  • Multi-core – two or more cores on one chip; can run instructions simultaneously → higher speed for multi-threaded programs.
  • Hyper-Threading (Intel) – one physical core acts as two logical processors; better resource utilization.

14. Memory

Memory is the electronic holding place for the instructions and data a computer needs to reach quickly.

Characteristics of Primary Memory

  • Faster than secondary memory
  • Semiconductor based
  • Usually volatile
  • Computer cannot run without it

How Memory Works

When you open a program it is loaded from secondary → primary (RAM). Primary is fast so CPU can access it quickly. Memory is volatile – data lost when power is off. Saved files go to secondary storage.

Types of Memory

1. Primary Memory (Main Memory)

RAM (Random Access Memory) – Volatile. Temporary storage for programs/data being executed.

  • SRAM (Static) – uses transistors/flip-flops; retains state as long as power is on; faster, less access time.
  • DRAM (Dynamic) – uses capacitors; needs refreshing every few ms; slower than SRAM.

ROM (Read Only Memory) – Non-volatile. Permanent; stores system operation info. We can only read it.

  • MROM – Masked ROM (hard-wired, low cost)
  • PROM – Programmable once by user
  • EPROM – Erasable by UV light (~40 min)
  • EEPROM – Electrically erasable & reprogrammable (~10,000 times, 4–10 ms)

2. Secondary Memory (Auxiliary / Backup)

Non-volatile, large capacity, cheaper, slower. CPU cannot access it directly – data first moved to main memory.

  • Magnetic Tapes
  • Magnetic Disks (Hard disks – tracks & sectors)
  • Optical Disks (CD, DVD – laser based)

3. Cache Memory

High-speed semiconductor memory between CPU and main memory. Stores frequently used data/programs.

Advantages: Faster, less access time, temporary storage of hot data.
Disadvantages: Expensive, small size.

16. Algorithms

An algorithm is a step-by-step procedure of solving a problem. Derived from the name of 9th-century Persian mathematician Al-Khwarizmi.

Formal definition: A collection of unambiguous instructions executed in a specific sequence to produce an output in a finite amount of time for a given set of input data.

Properties of an Algorithm (Must possess all)

  1. Finiteness – Must terminate after finite number of steps
  2. Definiteness – Each step must be accurate and clear
  3. Effectiveness – Each step must be primitive and performable in finite time
  4. Independent – Independent of any programming language
  5. Input / Output – Zero or more inputs → one or more outputs

Methods for Developing an Algorithm

  1. List the data needed (input) and the end result (output)
  2. Describe the steps to process input → output; break complex processes into simpler statements
  3. Test the algorithm with different data sets
Example: Addition of two numbers Step 1: Start Step 2: Get two numbers a and b as input Step 3: Add a & b and store result in c Step 4: Print c Step 5: Stop

17. Building Blocks of Algorithm

The basic building blocks are: Statements, Control Flow and Functions.

Statements

A single action in a computer. Can be:

  • Input data
  • Process data
  • Output data

18. Control Flow

The process of executing statements in a given sequence. Three ways:

1. Sequence

Instructions executed one after another consecutively.

Example: Average of three numbers Step 1: Start Step 2: Get a, b, c Step 3: Sum = a + b + c Step 4: Average = Sum / 3 Step 5: Print Average Step 6: Stop

2. Selection

Transfer control based on a condition (IF-THEN-ELSE).

Example: Largest of two numbers Step 1: Start Step 2: Get a, b Step 3: IF a > b THEN Step 4: PRINT “A is Large” Step 5: ELSE Step 6: PRINT “B is Large” Step 7: ENDIF Step 8: Stop

3. Iteration (Looping / Repetition)

A set of statements executed again and again based on a condition.

Example: Print natural numbers up to n Step 1: Start Step 2: Get n Step 3: i = 1 Step 4: IF i <= n THEN go to Step 5 ELSE go to Step 7 Step 5: Print i; i = i + 1 Step 6: Go to Step 4 Step 7: Stop

19. Functions

A function is a sub-program (block of instructions) that performs a particular task. Complex problems are divided into smaller tasks.

Benefits

  • Reduction in lines of code
  • Code reuse
  • Better readability
  • Information hiding
  • Easy to debug & test
  • Improved maintainability
Main (calling) function: Step 1: Start Step 2: Call add() Step 3: Stop Sub-function add(): Step 1: Function start Step 2: Get a, b Step 3: c = a + b Step 4: Print c Step 5: Return

20. Pseudo Code

Pseudo = False, Code = Set of instructions.
A short, readable set of instructions written in English-like language to explain an algorithm. Language-independent.

Rules

  • Write one statement per line
  • Capitalize keywords
  • Indent to show hierarchy
  • Keep statements language independent

Common Keywords

BEGIN / END INPUT / GET / READ COMPUTE / ADD / SUBTRACT OUTPUT / PRINT / DISPLAY IF / ELSE / ENDIF WHILE / ENDWHILE FOR / ENDFOR // comment

BEGIN GET a, b ADD c = a + b PRINT c END

Advantages

  • Program independent
  • Easily understandable
  • No standard syntax
  • Easy to translate to any language
  • Easy to modify

Disadvantages

  • Not visual
  • No picture of the design
  • No standardized style
  • Harder for beginners than flowchart

21. Flowcharts

Graphical / diagrammatic representation of the process of solving a problem. Shows steps in sequential order.

Rules

  • Clear, neat and easy to follow
  • Logical start and finish
  • Only one flow line out of a process symbol
  • Only one flow line into a decision; two or three may leave
  • Only one flow line with a terminal symbol
  • Write briefly & precisely inside symbols
  • Avoid intersection of flow lines

22. Iteration & Recursion

Iteration

A sequence of statements executed until a specified condition is true. Implemented using For loop or While loop.

FOR version (Print n natural numbers) BEGIN GET n INITIALIZE i = 1 FOR (i <= n) DO PRINT i i = i + 1 ENDFOR END WHILE version BEGIN GET n INITIALIZE i = 1 WHILE (i <= n) DO PRINT i i = i + 1 ENDWHILE END

Recursion

A function that calls itself repeatedly until a specified base condition is satisfied.
Factorial (Recursive) Main: BEGIN GET n CALL factorial(n) PRINT fact END factorial(n): IF (n == 1) THEN fact = 1 RETURN fact ELSE RETURN fact = n * factorial(n-1)

23. Efficiency of Algorithms (Complexity)

Factors for analyzing an algorithm: Efficiency, Simplicity, Generality, Range of Growth, Order of Growth. Efficiency is the most important.

Performance Analysis

  1. Time Complexity – Amount of time required to execute the algorithm
  2. Space Complexity – Amount of storage required

Time Complexity

Total time = Variable part (run time) + Fixed part (compile time).
Represented as T(n) – number of steps (each step takes constant time).

Space Complexity

S(P) = C + SP
C = fixed space (instructions, simple variables, constants)
SP = variable space (depends on instance size)

Also = Instruction space + Data space + Environment stack space.

26. Exam-Style Practice Questions

  2. M1, M2, M3 are marks in 3 tests. Write an algorithm to find the average of the best 2 marks.

1. Clear steps (Start → Input → Process → Output → Stop)
2. Corresponding pseudo code or flowchart
3. Mention the control structures used (sequence / selection / iteration)
